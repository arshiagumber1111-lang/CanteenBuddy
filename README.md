# Canteen Buddy - Canteen Management System

A C++ project that simulates a college canteen management system.

## Features
- Display and search food items
- Add items to a cart
- Remove quantities from the cart
- Generate bills and apply discounts
- Simulate payment methods
- Manage menu items
- Store menu data using file handling

## Technologies Used
- C++
- File Handling
- Data Structures
- Git and GitHub

## How to Run

Compile using g++:

`g++ main.cpp -o canteen`

Run on Windows PowerShell:

`.\canteen.exe`

## Project Purpose
Created to practice C++ programming and file handling.
